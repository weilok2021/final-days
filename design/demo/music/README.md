# Music for the demo video

`happy-song.mp3` is the first 30 seconds of "Happy Song" by Pro Sensory,
published under CC0 1.0 (public domain) on OpenGameArt:
https://opengameart.org/content/happy

The clip is re-encoded at 128 kb/s from the original file. CC0 needs no
attribution; this note records where it came from. To use another track, set
`FD_DEMO_MUSIC` to its path when running `npm run demo`, or replace this
file. Only `demo-music.mp4` carries sound; the GIF and `demo.mp4` are silent.

An earlier version used "Contemplation" by Joth (also CC0, on OpenGameArt at
https://opengameart.org/content/contemplation-0), a slow piano piece. The
user swapped it for a brighter track to suit LinkedIn and portfolio use.
