# Music for the demo video

`contemplation.mp3` is the first 30 seconds of "Contemplation" by Joth,
published under CC0 1.0 (public domain) on OpenGameArt:
https://opengameart.org/content/contemplation-0

The clip is re-encoded at 128 kb/s from the original 160 kb/s file. CC0 needs
no attribution; this note records where it came from. To use another track,
set `FD_DEMO_MUSIC` to its path when running `npm run demo`, or replace this
file. Only `demo-music.mp4` carries sound; the GIF and `demo.mp4` are silent.
